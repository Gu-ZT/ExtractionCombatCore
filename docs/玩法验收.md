# 搜刮玩法验收

验收使用同一份内置维修柜和背包定义，对照[玩法设计](搜刮玩法设计.md)的 17 个场景。客户端测试使用实际 Minecraft 进程、可重绑按键、菜单鼠标输入和 AnvilLib 网络连接。游戏测试在 NeoForge 专用 GameTest 服务端执行。

| 场景 | 核对内容 | 运行方式 |
|---|---|---|
| 1. 受限库存 | 主背包关闭，快捷栏从三格减为零。禁用位置只取不放，背包位仍可操作，拾取超出容量的余量留在地面。 | 库存 GameTest |
| 2. 四向拖动与凹口 | 靠近四边后抓取格仍跟随指针，中心和等距角维持朝向；竖放挂钩后可独立点取凹口中的铁粒。 | 图形客户端、形状测试 |
| 3. 双击直接转移 | 可合堆、可在空位转向的物品优先直接转移，邻近物品的位置不变。 | 网格测试、双客户端 |
| 4. 按需整理 | 可解时才提交完整布局；空间碎片、跨分区无解或取消搜索时，原布局和物品数量不变。 | 网格与分批搜索测试 |
| 5. 多人搜索 | 甲先发现铁粒，乙首次开柜仍见遮罩；两人处理同一叠物品只会成功一次。 | 双客户端、专用服务端 |
| 6. 两种槽位图标 | 挂钩的网格图随六格轮廓转向，原版快捷栏采用独立的单格贴图。 | 客户端绘制与像素比对 |
| 7. 贴图回退 | 缺少网格图、网格图比例错误或单格图缺失时，对应位置采用默认显示；另一字段仍独立生效。 | 客户端绘制与像素比对 |
| 8. 谓词优先级 | 标签、精确物品和限定组件的规则同时命中时，具体规则整体胜出。 | 真实注册物品及组件的规则测试 |
| 9. 禁用品质 | 字符串与对象两种 `disable` 形式均取消品质显示。 | 规则解析测试 |
| 10. 共享品质 | 两个命名空间的物品使用被高优先级数据包覆盖后的名称和颜色。 | 从两个磁盘数据包加载规则 |
| 11. 引用错误 | 缺失品质的错误定位到物品、字段和品质 ID，仍可读取上一批有效规则。 | 规则重载测试 |
| 12. 品质及遮罩 | 原版稀有度、共享品质和内联品质分别解析；未发现时个人视图不含该物品，发现后显示轮廓。 | 规则测试、双客户端 |
| 13. 密码与摩斯 | 密码区分前导零，音频短长音和图案表达同一套点划编码，错误后可以重试。 | 挑战 GameTest、客户端 |
| 14. 滚动锁 | 三位和九位两端均可依次锁定，误按保留已锁位，暂停期间再次按键不会延长暂停。 | 挑战 GameTest |
| 15. 成功扣费 | 钥匙路线只扣一件，译码器保留，中断路线保留道具。 | 路线 GameTest、双客户端 |
| 16. 加速破译 | 无操作也能自然完成；单次经过白条只加速一次，冷却后可继续。 | 挑战 GameTest |
| 17. 存档与重载 | 重新进入同一世界复核背包、坐标、朝向和解锁状态；缩容后分别检查新旧实例与待放入列表。 | 实际世界重进、数据包重载 GameTest |

## 26.3 实测记录

在 Java 25、NeoForge 26.3.0.100 与 AnvilLib 2.0.0 上运行数据生成、发行构建、10 项 JUnit 和 9 项专用服务端 GameTest。专服验证了背包的死亡掉落与保留、缩容重载、保存与读回。演示工具架首批生成四个铁粒，取走后再补入挂钩，玩家需重新搜寻才能看到它。

两名玩家各持一把钥匙同时长按开启维修柜，甲消耗钥匙，乙保留钥匙。甲发现挂钩后，乙重新打开柜子的第一帧仍完全遮盖。双方竞争同一叠铁粒，甲取到四个，乙的过时请求没有产生重复物品。服务器在线切换三格、零格和九格快捷栏，两端的遮罩、主手和 SDL 滚轮回绕都跟随新规则。主机验证四向拖动、凹口插放、原版槽位贴图（108 个不透明像素全部匹配），随后退出并重新进入世界，背包布局和已开柜状态均保留。

独立单人客户端使用键盘、鼠标和实际声音，完成了数字密码、音频摩斯、图案摩斯、滚动锁和加速破译。双人的日志与 11 张截图在 `build/playtest/dual-01`，五锁的日志与 6 张截图在 `build/playtest/puzzle-01`。构建和专服记录在 `build/qa-tools/release-263.log`，数据生成记录在 `build/qa-tools/final-263.log`。

## 本地复验

先运行 `./gradlew runData`，然后运行 `./gradlew build runGameTestServer`。双客户端运行目录相互独立。在两个终端中分别运行 `./gradlew runPlayHost -PplaytestDir=<本次验收的绝对目录>` 和 `./gradlew runPlayGuest -PplaytestDir=<同一目录>`。每次使用新目录，测试只监听本机回环地址。

单机开锁界面使用 `./gradlew runPlayPuzzles -PplaytestDir=<另一个新目录>`。客户端会在验收目录写入角色结果和截图。开发测试类与缩容数据包只参与开发运行，发行 JAR 包含玩家所需的模组和演示资源。
